# Monitor de Sistema 🖥

Monitor simples feito em Python com interface gráfica nativa.

## ✨ Funcionalidades

*  Mostra os IPs da máquina
*  Mostra processos em execução
*  Mostra serviços do Windows
*  Mostra conexões de rede ativas
*  Possui filtro por nome, IP ou porta
*  Atualiza automaticamente

## 📦 Instalação

```bash
pip install psutil

python main.py
