# Monitor de Sistema 🖥️

Monitor simples feito em Python com interface gráfica.

## Funcionalidades

* Mostra os IPs da máquina
* Mostra processos em execução
* Mostra serviços do Windows
* Mostra conexões de rede
* Possui filtro por nome, IP ou porta
* Atualiza automaticamente

## Instalação

```bash
pip install psutil
```

## Como usar

```bash
python main.py
```

## Tecnologias

* Python
* Tkinter
* Psutil
